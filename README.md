# Instagram DB - SQL Project

A complete database design for an Instagram clone, built with MySQL.

🔗 **Live Repo:** https://github.com/sravaniedu23-sys/instagaram-db

### 📌 Project Overview
This project contains the database schema and SQL queries for an Instagram-like social media application. Designed for Cognizant & other interview preparations.

# Tables Included
- `accounts` - User accounts
- `posts` - User posts
- `likes` - Post likes
- `comments` - Comments on posts
- `followers` - Follower relationships

#Tech Stack
- MySQL / SQL
- GitHub for version control

#Features
- User account management
- Post creation and management
- Like & comment functionality
- Follow/Unfollow system
